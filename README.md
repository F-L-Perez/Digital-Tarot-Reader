# Digital-Tarot-Reader
> Web App that shuffles tarot cards in different spreads.

<div align="center" width="400">  <img height="400" alt="Preview of Beta Digital Tarot Reader" src="https://github.com/user-attachments/assets/c6dbde58-de80-4a82-87bb-adc818aee1ac" /></div>

Uses: (Vanilla) HTML5 and JavaScript.

## Development Path

✅Beta: 
- [x] Randomize Major and Minor Arcana
- [x] Reverse card function
- [x] Toggle options to include minor arcana or not.
- [x] Tarot Card Description
- [x] Easy-to-read code comments
  
Pre-Release: 
- [ ] Simple card spreads (single, duo, triple past/present/future)
- [ ] Change card styles
- [ ] Light and Dark Theme
- [ ] Shuffle tarot cards in different spreads

Release:
- [ ] More animation
- [ ] Add different languages
- [ ] (More) Different spreads
